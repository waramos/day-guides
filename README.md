# California Day Guides

A growing collection of practical, shareable day-trip guides for California, with an emphasis on Northern California.

## Guides
- [Point Reyes & Tomales Bay](guides/point-reyes/)

## Structure
- `index.html` — site directory / homepage
- `guides/<slug>/index.html` — one page per guide
- `assets/` — shared stylesheet and locally hosted SVG artwork
- `.github/workflows/pages.yml` — GitHub Pages deployment

All imagery in the initial guide is repository-hosted SVG artwork so the website has no external image CDN dependency.
